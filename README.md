# Nomadic Atlas for Android

A travel journal on a map of India: pin the places you've been and want to go, keep photos, stories and voice notes, explore treks, and use Traveller mode on the road.

## Download

**[Download the latest APK](https://github.com/duttabikram32-sudo/nomadic-atlas-app/releases/latest/download/nomadic-atlas.apk)**

Older versions: [all releases](https://github.com/duttabikram32-sudo/nomadic-atlas-app/releases)

## Install

1. Open the download link on your Android phone. The file downloads (about 80 MB).
2. Tap the downloaded file. If Android asks, allow installing from this source (Settings → *Allow from this source*), then go back and tap **Install**.
3. If Play Protect says the app is unrecognised, tap **More details → Install anyway**. That's normal for apps that aren't on the Play Store.

**Updating:** install the new APK over the old one. **Don't uninstall first**: your places, photos and stories are stored only on your phone, and uninstalling deletes them.

Your data never leaves your phone unless you make a backup yourself.
